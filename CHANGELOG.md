# Changelog

All notable changes to zodcat will be documented here.

## [0.1.0] - 2026-10-23

Initial public MVP.

- Visual component and props editor for json-render catalogs.
- Zod code generation with a copy-ready `defineCatalog` output.
- Live guardrails for escape hatches, unbounded props, invalid enums, duplicate keys, and oversized catalogs.
- Per-component Props / Code view with independent copy.
- Built-in templates, local autosave, undo for destructive actions, and clipboard fallback.
- English and Chinese interface, including built-in catalog content.
